Open a backup independently

Slovensky: Otvorte zálohu svojím obnovovacím kódom (12 alebo 24 slov alebo QR kód). Všetko prebieha len vo vašom prehliadači.

This file opens an encrypted backup from an app that uses the regino-crypto core, using your recovery code (12 or 24 words, or the QR code from the recovery sheet). It runs only in your browser – nothing is sent to the internet (you can open it offline too).

If the backup opens, this confirms that the app encrypts with the public code from github.com/TPCreator/regino-crypto. Tool version: __VERSION__.

The photo is processed only here in your browser and is not stored anywhere.

Slovensky: prílohy sú v priečinku s kúskami vedľa zálohy (napr. „kusky“) – vyberte ho a kliknite na súbor.

    QR code reading: jsQR (Apache-2.0, github.com/cozmo/jsQR).
